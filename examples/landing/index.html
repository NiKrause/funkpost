mesh-todo

OrbitDB on hardware

A todo list replicating between two phones with no IP path anywhere. Signed entries, an access controller, a verifiable log — and a sync pane that prices every frame. This is the demo that first crossed the air, on 4 September 2026.

/funkpost/termine/

Trying them without a radio

Append ?mesh=bc and two browser tabs play the two devices, using a BroadcastChannel where the LoRa link would be. It has to be two tabs in the same browser profile — that channel does not cross profiles.

  • mesh-todo: open it twice with ?mesh=bc.
  • Termine: one tab with ?mesh=bc&room=test&role=salon, the other with role=customer.

With a Meshtastic node over Web Bluetooth, drop the parameter and press Connect — Chrome or Edge, and an HTTPS page, because Web Bluetooth refuses anything less.
